# Instructivos y material comercial

- `instruction.md`: manual de uso y ficha tecnica del sistema (usuario + administrador). Es la fuente principal; al agregar o cambiar un modulo, actualizalo aqui primero.
- `guia-uso.html`: guia visual de uso.
- `ejemplo-compromiso.html`: ejemplo del compromiso mostrado al usuario.
- `PENDIENTES.md`: mejoras identificadas para futuras iteraciones.
